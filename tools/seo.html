SEO Inspector

See how a page appears when it’s shared. Explore the metadata behind it.

Tries direct access, then sends the public URL to Jina Reader if needed. The service may cache pages or limit requests. Use direct access or paste HTML for private content.

HTML is parsed in your browser. Preview images load only when you choose to load them. For JavaScript-generated tags, copy the rendered HTML from your browser’s developer tools.

01 / PREVIEW

Links, before you share them

Open Graph and X cards, plus an illustrative search snippet with the source of each field.

02 / INSPECT

The details that matter

Titles, descriptions, canonicals, robots directives, language alternatives, and every meta tag.

03 / EXPLORE

Structured data, unpacked

Every JSON-LD block, formatted for reading, with detected types and individual syntax errors.

Some sites block automated requests. If a URL cannot be fetched, paste its HTML to inspect it.

Link & search previews

Illustrative previews. Platforms can crop images, omit fields, use cached metadata, or choose different text. Image loading contacts the image host; a loaded image does not prove that a crawler can access it.

Things to check

Checks of the supplied HTML, not an SEO score or proof of indexability.

    Open Graph & X tags

    Original order is preserved. Repeated Open Graph properties can be intentional; previews use the first value.

    JSON-LD structured data

    Checks JSON syntax only. Contexts are not fetched, and schema rules or rich-result eligibility are not validated. Microdata and RDFa are not expanded.
